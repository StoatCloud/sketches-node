Sketches

A set of experiments and explorations, mostly using the regl WebGL library, some computed on the GPU and some on the CPU. Sketches below are grouped for VM-friendly viewing versus GPU-heavy WebGL; style tags mirror the Radiant gallery vocabulary (submodule at radiant/). The source for all content and projects on this site can be found here.

Comments? Questions? Let me know @rreusser@mathstodon.xyz.

Gallery layout and tags follow the Radiant shader gallery vocabulary (see radiant/ submodule).
